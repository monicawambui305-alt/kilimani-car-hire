## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- npm or bun

### Installation
```bash
# Clone the repository
git clone https://github.com/monicawambui305-alt/kilimani-car-hire.git

# Navigate into project directory
cd kilimani-car-hire

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Production Build
```bash
npm run build
npm run preview
```
